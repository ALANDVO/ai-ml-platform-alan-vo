## [1.0.0] - 2026-10-12

### Added
- Complete AI/ML training platform with modular FastAPI backend and React frontend.
- Experiment tracking, trial metrics history, and lineage tracking.
- Model registry with versioning, artifact staging, and rollback support.
- Bayesian hyperparameter optimization and search spaces.
- Real-time training loop monitoring and simulated trainer execution.
- LLM-assisted architecture recommendations and experiment analysis with provider adapters.
- Comprehensive unit and integration test suites for both backend and frontend.
